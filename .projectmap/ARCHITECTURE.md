## Overview
ANEMLBreezeASR is a macOS 13+ SwiftUI app that auto-generates subtitles: it extracts audio with FFmpeg, transcribes Taiwanese-Mandarin speech on-device via WhisperKit (Breeze-ASR-25 CoreML model), optionally corrects/translates the SRT through an OpenAI-compatible LLM, and can burn subtitles back into video. It follows MVVM with a service layer — Views → ViewModels → Services → external tools (FFmpeg / WhisperKit / OpenAI) — using Swift async/await throughout. The UI is a single four-tab window (Generate / Burn / Correct-Translate / Settings), and all user-facing text is Traditional Chinese (繁體中文).

## Conventions
- **MVVM + service layer**: Views are thin, ViewModels are `@MainActor @ObservableObject` orchestrators, Services own all I/O and third-party calls. Keep layers separated.
- **Per-service error enums**: each service defines its own (`FFmpegError`, `WhisperKitError`, `LLMError`, `SubtitleError`); errors surface to users via NSAlert.
- **async/await throughout**; FFmpeg process execution bridges to async via `CheckedThrowingContinuation`.
- **FFmpeg** is a required external system dependency, located from `/opt/homebrew/bin/ffmpeg`, `/usr/local/bin/ffmpeg`, or `which ffmpeg`.
- **WhisperKit** downloads a ~3GB model on first run to `~/Library/Application Support/ANEMLBreezeASR/HubCache/`, reusing VibeTyping's cache if present.
- **LLM correction/translation** calls the OpenAI-compatible API directly over `URLSession` (no vendor SDK), chunks the SRT to stay under token limits, paces requests via a configurable `requestIntervalSeconds` throttle + retry/backoff, and reattaches the original timestamps afterward (see `LLMService.splitSRTIntoChunks`/`throttleIfNeeded` + `SubtitleService.reattachOriginalTimestamps`).
- All UI strings and documentation are in Traditional Chinese (繁體中文).
